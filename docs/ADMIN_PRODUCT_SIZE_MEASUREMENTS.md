# مدیریت اندازه‌ها و جدول سایزبندی

در صفحه مدیریت هر محصول، بخش «جدول اندازه‌گیری و مشخصات سایز» سه نوع اطلاعات را مدیریت می‌کند:

1. **اندازه مشترک محصول و سایز**: برای تمام رنگ‌های محصول مشترک است؛ مانند دور سینه، قد لباس، عرض شانه و قد آستین.
2. **توضیحات سایز**: متن راهنمای مستقل برای هر سایز همان محصول.
3. **اندازه اختصاصی رنگ و سایز**: برای مواردی که یک ترکیب رنگ و سایز با جدول مشترک تفاوت دارد. داده اختصاصی در خروجی عمومی کاتالوگ بر مقدار مشترک اولویت دارد.

## APIهای استفاده‌شده

- `GET/POST/PATCH /api/admin/catalog/product-measurements/`
- `GET/POST/PATCH /api/admin/catalog/product-size-descriptions/`
- `GET/POST/PATCH /api/admin/catalog/variant-size-measurements/`

این مرحله فقط از APIهای موجود استفاده می‌کند و migration جدید ندارد. دسترسی خواندن و نوشتن همچنان به حساب staff فعال و مجوز مدل متناظر Django نیاز دارد. برای مثال:
- `catalog.view_productsizemeasurement` و `catalog.change_productsizemeasurement`
- `catalog.view_productsizedescription` و `catalog.change_productsizedescription`
- `catalog.view_variantsizemeasurement` و `catalog.change_variantsizemeasurement`

API فعلی حذف فیزیکی یا غیرفعال‌سازی ردیف اندازه را ارائه نمی‌کند؛ بنابراین این رابط فقط افزودن و ویرایش را نمایش می‌دهد و وانمود نمی‌کند که حذف انجام می‌دهد.

## قواعد

- اندازه‌ها و مقادیر به‌صورت متن ذخیره می‌شوند تا مقادیر سفارشی مثل «حدود ۹۶»، بازه‌ها یا واحدهای مختلف پشتیبانی شوند.
- عنوان، مقدار و واحد برای هر ردیف مستقل‌اند؛ مدیر می‌تواند فیلدهای دلخواهی اضافه کند.
- جایگاه ردیف‌ها به ترتیب ثبت‌شده API وابسته است.
- تغییرات از API مدیریت کاتالوگ عبور می‌کنند؛ این صفحه مستقیماً به دیتابیس یا موجودی دست نمی‌زند.
- هیچ تغییری در قیمت، موجودی، سفارش، پرداخت، SEP، OTP، ویترین عمومی، جست‌وجوی دسکتاپ، فوتر یا نماد اعتماد ایجاد نشده است.
