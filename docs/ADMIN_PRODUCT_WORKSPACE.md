# فضای اختصاصی مدیریت محصولات

مسیر رابط: `/[locale]/admin-panel/catalog`

## قابلیت‌های این مرحله

- دریافت فهرست صفحه‌بندی‌شده محصولات، دسته‌بندی‌ها، مجموعه‌ها، سایزها، رنگ‌ها و ترکیب‌های رنگ/سایز از API مدیریت.
- ایجاد و ویرایش محصول با قیمت به تومان، قیمت تخفیف، توضیحات، دسته‌بندی و مجموعه‌ها.
- انتشار یا خارج‌کردن محصول از انتشار با تغییر `is_active`.
- افزودن رنگ به محصول با نام، شناسه انگلیسی و کد HEX؛ کد عددی کارت فقط از سمت مدل و شمارنده تراکنشی تولید می‌شود.
- افزودن سایز و SKU به هر رنگ.
- نمایش موجودی جداگانه هر ترکیب رنگ/سایز و ثبت افزایش/کاهش فقط از API گردش موجودی همراه با دلیل.
- لینک پنل مدیریت در منوی همبرگری فقط برای حساب‌هایی که `authApi.me()` آن‌ها `is_staff=true` برمی‌گرداند.

## امنیت

- نشست Django و CSRF از `apiRequest` فعلی استفاده می‌شوند.
- رابط کاربری جایگزین مجوزهای سمت سرور نیست؛ endpointها همچنان `is_staff` و مجوز مدل مربوطه را بررسی می‌کنند.
- موجودی مستقیماً در فیلد `stock_quantity` نوشته نمی‌شود و تمام تغییرها از سرویس حسابرسی‌شده موجودی عبور می‌کنند.

## خارج از محدوده

- آپلود، پردازش، حذف و مرتب‌سازی تصاویر در این مرحله وجود ندارد؛ باید به pipeline فعلی WebP متصل شود.
- ایجاد/ویرایش دسته‌بندی و مجموعه، واژگان سایز، جدول اندازه‌ها و توضیحات در این مرحله در UI ارائه نشده‌اند.
- ویرایش زنده فروشگاه، صفحه اصلی، بنرها، تم‌ها، گردش‌کارها و سایر ماژول‌های مدیریتی در فازهای بعدی هستند.
- این PR صرفاً کد است؛ دیپلوی Production انجام نمی‌دهد و وضعیت سفارش‌ها و SEP را تغییر نمی‌دهد.
