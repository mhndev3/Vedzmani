# پنل اختصاصی سفارش‌ها

مسیر رابط: `/[locale]/admin-panel/orders`

## API

هر دو مسیر زیر زیرساخت احراز هویت نشست Django و CSRF موجود را حفظ می‌کنند و فقط برای حساب فعال `is_staff` دارای مجوز `orders.view_order` قابل خواندن هستند:

- `GET /api/admin/orders/`: فهرست صفحه‌بندی‌شده، ۲۰ رکورد در صفحه و حداکثر ۵۰ رکورد.
- `GET /api/admin/orders/<id>/`: جزئیات یک سفارش.

پارامترهای اختیاری فهرست:

- `search`: شناسه عددی سفارش، SKU یا نام snapshot محصول.
- `status`: یکی از وضعیت‌های تعریف‌شده مدل سفارش.
- `payment_status`: یکی از وضعیت‌های تعریف‌شده پرداخت.
- `page` و `page_size`: صفحه‌بندی.

## حفاظت از اطلاعات مشتری

مجوز `orders.view_order` فقط مشاهده سفارش و اقلام را می‌دهد. شماره تلفن در این حالت ماسک می‌شود و اطلاعات گیرنده/نشانی خالی می‌ماند. نمایش کامل شماره تلفن و اطلاعات تحویل علاوه بر آن نیازمند مجوز مستقل `orders.view_order_pii` است. اطلاعات شخصی در search/filter قابل جست‌وجو نیستند. پاسخ‌ها `no-store` هستند.

## مرزهای عمدی نسخه اول

این API فقط GET دارد. ایجاد، تغییر وضعیت، لغو، بازپرداخت، تغییر وضعیت پرداخت، تغییر اقلام و اصلاح موجودی از این پنل ممکن نیست. این عملیات تا زمان تعریف گردش‌کار تأییدشده برای پرداخت، ارسال، لغو و برگشت موجودی عمداً ارائه نمی‌شوند. مبلغ سفارش مطابق مدل فعلی، هزینه ارسال را شامل نمی‌شود.

## مجوزهای Django

- `orders.view_order`: مشاهده فهرست، جزئیات و اقلام.
- `orders.view_order_pii`: مجوز مستقل و صریح برای مشاهده شماره تلفن کامل و اطلاعات تحویل.

هیچ مجوزی به‌صورت خودکار به کاربران یا گروه‌ها اعطا نمی‌شود.
